# Live2D 本機導入開發計畫

建立日期：2026-10-19。用途：僅供使用者本人本機使用，不部署、不公開散布。

## 目標與現況

在現有 Vue 3 + TypeScript 舞台中加入 Cubism Web 模型，沿用角色、表情 SSE、語音與 SQLite。現有 SVG／圖片立繪保留作為回退。2026-10-19 已使用本機 CubismSdkForWeb-5-r.5 完成 Core 與官方 Haru 試演；尚未綁定正式角色。

本階段與原 P1–P5 分開編號，分批驗收；不一次改動對話、記憶與儲存架構。

## 免費模型與 SDK

- 官方免費模型頁：https://www.live2d.com/en/learn/sample/
- 官方 SDK：https://www.live2d.com/en/sdk/download/web/
- 官方範例及 Resources：https://github.com/Live2D/CubismWebSamples
- 模型條件：https://www.live2d.com/en/learn/sample/model-terms/

第一個驗證模型選用官方 SDK Resources 內的 Haru；需要可執行匯出檔（model3.json、moc3、textures），不是僅有 PSD 或 cmo3 編輯原檔。可改選官方其他範例，但必須檢查個別角色條件與 SDK 支援版本。

官方下載頁要求閱讀並同意 Proprietary／Open Software License，並載明下載或啟動構成同意。由使用者自行在官方頁完成下載；安裝指令只讀取使用者已下載解壓的 SDK，不代勾條款、不填電子郵件、不從未授權 CDN 取 Core。免費提供不等同無使用條件。

## 架構

```text
CharacterStage（背景＋角色）
 ├─ 現有 SVG／圖片（預設及載入失敗回退）
 └─ Live2DStage → Cubism Web adapter → 本機 Core／Framework

AI expression 事件 → 角色表情映射 → 演出控制器
TTS 實際播放 → Web Audio 音量 → 嘴型
SQLite → 模型索引、角色映射與舞台配置（不保存逐幀狀態）
```

官方 SDK 產生的執行檔與範例放在 `public/live2d/local/`，此目錄不進版本控制。應用程式正常建置不依賴使用者已安裝 SDK；未安裝仍可聊天。

實作：
- `model3.json` 的 `Expressions`／`Motions` 經過相對路徑驗證才載入（表情 ≤ 64、動作 ≤ 128；拒絕外部網址、上層目錄、錯誤副檔名、重複名稱）。
- 角色設定新增選用欄位 `expressionMap`、`motionMap`，不需要資料庫遷移；沒有對應的舊角色維持原樣。
- 演出控制器 `src/live2d/director.ts` 不依賴 WebGL：
  - 一個模型實例對應一個控制器。
  - 只有在同一段對話中「同一則回覆的狀態改變」或「新回覆開始生成」時，才會播一次性動作。
  - 切換對話、開啟歷史、重新載入模型，只套用表情，不重播動作。
- 只會播放「角色與素材 → 角色呈現」中指定的動作（白名單），AI 輸出無法觸發任意動作。
- 待機動作會循環。同等或更高優先度的動作會取代正在播的動作（後到的狀態優先），較低的不會打斷。
- 編輯器直接從 model3.json 讀取表情與動作清單，可依名稱自動對應，並能在預覽中「試看」表情、「試播」動作。

  - 一則回覆依序觸發「生成中」動作 → 表情換成 F08（思考）→「開始回覆」動作。

## B4：語音嘴型

- [x] 將語音「請求中」與「實際播放」分開。
- [x] 本機 HTTP TTS 音訊以 Web Audio 分析音量，平滑控制口型；停止即閉嘴。
- [x] 瀏覽器內建語音僅提供明確標示的簡化說話動畫，不聲稱精確音訊同步。
- [ ] 音素／viseme 精細口型另列後續，取決於 TTS 時間標記支援。

實作：
- `src/chat/voice.ts` 的 `phase` 分成 idle、requesting、playing：
  - 本機 TTS：下載音訊期間為 requesting；`audio.play()` 開始後才算 playing。
  - 瀏覽器語音：要等 `onstart` 才算 playing。
  - 按鈕依序顯示「♪ 朗讀」→「… 準備中」（可取消）→「■ 停止」。
- 音量嘴型：
  - 播放元素經 `MediaElementSource → Analyser → 喇叭`，每幀取 RMS 音量。
  - 低於約 0.015 視為底噪；張嘴比閉嘴快，看起來像音節而不是閃動。
  - AudioContext 在點擊時就建立並 resume，避免被自動播放政策擋下；仍無法量測時改用「簡化嘴型」並如實標示。
- 嘴型只跟著目前這段對話的角色：其他對話在說話時，舞台嘴型維持 0。停止或播放結束時立刻閉嘴。
- Adapter 的 `setMouth` 以 0.8 權重寫入模型的 LipSync 參數群組；模型沒宣告時改用 `ParamMouthOpenY`。
- 播放中顯示「♪ 音訊嘴型」或「♪ 簡化嘴型」標籤（附說明），設定頁也有文字說明兩者差異。

驗收：
- 70 項測試及正式建置通過，新增 4 項：音量映射與平滑、TTS 階段與量測嘴型、停止即閉嘴及無 Web Audio 的退回、較舊的請求被新請求取代。
- 隔離工作區實測：
  - 測試用假 TTS 輸出有音節起伏與靜音間隔的 WAV：準備中嘴型為 0；播放時嘴型在 0.93–0.99（音節）與 0.01–0.24（間隔）之間開合，並顯示「音訊嘴型」。
  - 切到瀏覽器語音後顯示「簡化嘴型」與說明。
  - 實測時瀏覽器面板在背景，畫格數被瀏覽器節流；嘴型數值正確，但沒有量測前景 FPS。

ZIP 匯入實作（2026-10-20）：
- 流程：「角色與素材 → 角色呈現 → 本機模型索引 → 匯入 ZIP 模型包」。
  1. 上傳後，伺服器解壓到 `data/live2d-staging/<token>/`，回報找到的模型、貼圖數、表情、動作、缺少的選用檔與略過的檔案。
  2. 確認後，模型移到 `public/live2d/local/models/<模型檔名>/` 並加入索引。有勾選時，會直接套用到目前編輯的角色。
  3. 安裝失敗會刪掉已複製的檔案；未確認的暫存一小時後清除。
- `vite preview` 用的 `dist/live2d/local/models` 會同步複製，所以不必重新 build 就能使用。
- ZIP 讀取器（`server/zip.ts`）只用 Node 內建 zlib：
  - 支援 stored／deflate，以及 UTF-8／Big5／GBK 檔名。
  - 拒絕 ZIP64 與加密檔。
  - 依 ZIP 記錄的大小限制解壓輸出，並驗證 CRC。
- 安全檢查（`server/live2dImport.ts`）：
  - 拒絕 `..`、絕對路徑、磁碟代號、控制字元、符號連結與大小寫重複的檔名。
  - 出現 JS／HTML／SVG／執行檔等就整包拒絕；其他非模型檔（cmo3、PSD 等）只略過不解壓。
  - PNG 與 moc3 依實際內容驗證；JSON 必須能解析。
  - 上限：ZIP 200 MB、2000 個檔案、解壓後 600 MB、單檔 150 MB、壓縮比 250 倍（防壓縮炸彈）。
  - 缺少 moc3 或貼圖時不能安裝；缺少表情、動作、物理等選用檔時只提出警告。
- 驗收：
  - 80 項測試通過，新增 5 項：ZIP 讀寫與損毀偵測、暫存報告、13 種惡意或格式錯誤的模型包、安裝／鏡像／不覆寫／取消、API 流程。

    - 測試建立的資料夾已刪除。
