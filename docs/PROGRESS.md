## Phase 05 — 表情、語音、轉場、長期記憶（完成）

資料庫 v2 → v3 自動遷移：角色補上表情、語音與記憶欄位；對話新增場景與記憶進度欄位；偏好補上語音設定。

### 表情

- 8 種表情：平靜、微笑、開心、難過、驚訝、害羞、生氣、思考。
- 有角色時，後端在 system prompt 加上表情規則，要求模型在回覆開頭輸出 `[表情:微笑]`。
- 串流時先暫存開頭，等確定是不是標籤；標籤會被拿掉，以 `expression` 事件送出，所以生成一開始就換表情。不認得的標籤當成一般台詞；token 只計算看得到的台詞。
- 送回模型的歷史會補回標籤，讓模型持續用同樣的格式。
- 每個角色可以為每種表情指定立繪，沒指定的使用預設立繪；內建的澪插畫會依表情改變眉毛、嘴型和腮紅。

### 轉場與場景

- 換表情：淡入加上輕微彈跳。換背景：0.7 秒交叉淡入淡出。系統設定減少動態效果時會關閉動畫。
- 每段對話可以從舞台左上角的場景名稱切換背景與場景名稱；沒設定就用角色預設。
- 被場景或表情使用中的素材不能刪除；引用不存在或類型不符的素材時拒絕保存。

### 語音

- 「♪ 朗讀」按鈕可以朗讀或停止目前回覆；設定裡可以開關語音、開關自動朗讀、切換引擎。
- 瀏覽器內建語音（Web Speech）：每個角色可選聲音、語速、音高，預設優先使用中文（台灣）語音；角色設定裡可試聽。
- 本機 TTS：在 `.env` 設定 `TTS_URL` 後，後端把 `{text, voice, speed}` 轉發給它，只接受回傳 `audio/*`；沒設定時選項會停用。

### 長期記憶

- 每個角色有自己的記憶清單（最多 200 則，每則最多 300 字），在「角色與素材 → 記憶」頁籤管理。
- 自動整理：一段對話累積 8 則新訊息後，回覆完成就讓模型把值得記住的事整理成 JSON 清單，已記得的不重複。也可以手動「整理目前對話」。
- 整理只在模型空閒時進行；整理途中送出新訊息，後端會取消整理讓對話先跑，之後再整理。
- 生成時後端從 SQLite 讀取記憶放進 system prompt：先放手動記憶，再放最新的自動記憶，總長度約 1500 字以內。
- 改過的自動記憶會變成手動記憶，超過上限時只會淘汰最舊的自動記憶。編輯角色表單不會蓋掉這段期間新增的記憶。
